# بازی ۵۰۰ معما 🧩

یک بازی معمایی فارسی و راست‌چین برای موبایل و رایانه.

## امکانات
- صفحهٔ خوش‌آمدگویی با دکمهٔ «ورود به بازی»
- امتیاز ۱۰تایی برای هر پاسخ درست
- ذخیرهٔ مرحله و امتیاز در مرورگر
- بررسی پاسخ با نرمال‌سازی حروف فارسی و املای نزدیک
- افکت گل و صدای کوتاه برای پاسخ درست

## انتشار با GitHub Pages
این مخزن یک فایل `index.html` و یک گردش‌کار GitHub Actions دارد. در مخزن به **Settings → Pages** برو و در بخش **Build and deployment**، گزینهٔ **Source** را روی **GitHub Actions** بگذار. بعد از اجرای موفق گردش‌کار، آدرس سایت معمولاً این است:

https://mohammadtaha7225-star.github.io/ramez-500/

## یادداشت
نسخهٔ فعلی ۵۰۰ مرحله دارد که از مجموعه‌ای از معماهای پایه استفاده می‌کند؛ بعضی معماها در مرحله‌های بعد تکرار می‌شوند. امتیاز و پیشرفت فقط در همان مرورگر ذخیره می‌شود.
